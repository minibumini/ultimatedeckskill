# 整页生图的制作与验收

## 实际生图入口

封面与内页都调用图像生成工具，正文、标题、场景与布局直接随完整页面生成。内置ImageGen是默认入口；环境实际提供Images2.5时可以使用。不能猜测模型名称、冒称特定版本可用，或只提供提示词而称已生图。

先读取当前imagegen技能与工具说明。内置路径不需要用户提供API key；普通批量使用逐页调用，不自行切换到CLI/额外收费API。生成完成后把选定图片保存到工作区，不能仅引用默认生成目录中的临时成果。记录页序、标题、准确文案、参考素材、提示词与实际工具入口，便于局部修订。

整页生图不等于无约束创作。将每页逐字锁定的中文和结构关系写清楚，让全套共享参考页、色板、字体方向和行业主角。封面可只生成主标题，讲师和日期后续准确合成；内页的标题和正文随画面生成。Logo、二维码、真实UI和准确数据对象保护原件，必要时单独精确合成，不以这项例外将普通正文全部改回原生排版。

参考花叔技能时只采用提示词、页型与教学方法。实际生图仍通过当前会话工具返回结果，不能通过再次启动Codex、扫描全局生成目录并取最新图片来认定成功；组装继续使用本技能的缺图/比例检查，不能悄悄跳过失败页。外部图片上传、网页桥接、额外API和人物蒸馏不属于默认课件流程。

## 密度与字号

正文28pt、标题40pt为优先视觉目标，信息量大的页面允许适度放宽。整页图片没有可直接读取的PPTX字号，不能设置硬性机器数值门槛。普通页保持大字和短句，密集页保留标题、正文、注释层级，尽量减少装饰并优化分组。

图片文字可按最终显示宽度估算：`等效pt ≈ 字面像素高度 ÷ 图片像素宽度 × 展示宽度(英寸) × 72`。字面高度不等于字体em尺寸，只用于粗略筛查；不能把这个估计当实际字体字号。以最终整页阅读和实际投影可读性判断，不因稍小于28/40一律重做。

需要学员阅读的关键内容不能成为细小文字。密集总览可保留较多信息，但要有清楚主次；确实难读时缩短文案、裁切局部截图、减少装饰或拆页。不要以“已经放宽字号”为由接受无法看清的正文。

PDF抽取pt只证明PDF文本尺寸；整页图片PDF无法证明原字号。OCR只能提取和辅助核对内容，不能还原真实字号。

## 逐页图像核验

- 核对主标题、正文、数字、单位、日期、Logo，检查多字、漏字、伪文字、错误符号和生成中文不自然。
- 流程箭头、层级、对照输入/输出与图表比例真实对应，不能只因画面漂亮判正确。
- 核对正式客户身份与旧客户残留，行业场景/产品与当前客户资料相符。
- 数据来源、时间与限定可追溯；效率数字没有证据则删除或标示演示数据。
- 看全套缩略图判断统一基调与节奏，再逐页放大核查文字与关键细节，重点看密集页和截图页。
- 共同检查核心意思能否快速辨认、文字层级、业务图文关系、全套一致性与内容准确性；评分仅作修订参考，不据主观分数宣称内容或工具实际验收通过。
- 普通图文错误通过图像编辑或局部重生修复，只重做受影响页；准确对象可保持原件或合成修复。
- 工程/医疗专业生成结果按用途说明示意/辅助与复核，不把未验证参数当真实技术成果。

## 图片组装

使用python-pptx/Pillow或已有组装能力；它们只组装生图结果和备注，不负责画课件。桌面环境先用`load_workspace_dependencies`找到具备依赖的Python，默认Python缺库时不假定无法制作。

`scripts/assemble_image_deck.py`读取按顺序排列的清单：

```json
{
  "title": "客户培训课件",
  "slides": [
    {"image": "pages/001.png", "title": "课程封面", "notes": "讲师备注"},
    {"image": "pages/002.png", "title": "岗位任务"}
  ]
}
```

图片相对路径以清单目录为基准。默认16:9，可用清单中的`canvas`指定`width_inches`与`height_inches`。不把非16:9图片静默裁切/拉伸：比例偏差超过0.5%报错，其余等比居中。真实制作先把不合比例的生成页修正后再组装。

```bash
python /absolute/path/ultimate-courseware/scripts/assemble_image_deck.py \
  /absolute/path/manifest.json \
  --pptx /absolute/path/final.pptx --pdf /absolute/path/final.pdf
```

脚本遇到空清单、所列图片不存在、尺寸无效或已有输出文件时明确中止，不覆盖源素材。它无法发现清单漏列的计划页面；组装前必须把清单逐项与已确定大纲核对，检查预期页数、页序与内容完整性。脚本产出的PPTX是每页一张图，允许整页移动/替换，图内文字无法逐项编辑；PDF同样是图片版。脚本可以读取图片来源元数据供维护，但不能从元数据证明图片确由ImageGen生成。

## 组装后检查与交付

核对PPTX/PDF页数与页序，打开成品并查看实际页面，检查图片完整性、比例、分辨率、备注与字体内容。需要时用PowerPoint/WPS或独立LibreOffice再渲染，验证文件中图片和原选定图片一致。静态图片课件无需证明原生文字可编辑。

完整制作交付图片型PPTX、PDF和简短验证说明；逐页高清图与提示词在可维护项目中保留，用户需要时提供。验收说明如实记录实际生图工具、文字与内容校核、密集页可读性、图内文字不可逐项编辑等使用边界。

本次请求仅为审阅或技能维护时完成相应范围，不自动生成新课件。生图任务未实际调用工具，或只使用了脚本绘制测试素材时，不能称用户课件已经完成。
