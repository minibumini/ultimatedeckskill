# 视觉与教学设计

本文件补充主技能的设计方法。用户当前要求优先；已有资料足够时直接设计，不把这些字段变成固定访谈。

## 客户化简报

从用户说明和现有素材提取最少信息：

| 字段 | 记录内容与处理方式 |
|---|---|
| 客户与行业 | 正式名称、业务范围、Logo 原件或核验过的官方来源；名称不明时只暂停依赖身份的设计 |
| 学员与任务 | 岗位、当前难点、培训后需要完成的工作；采用客户熟悉的对象和术语 |
| 课程与场景 | 主题、目标、现场/录播/阅读用途、已给出的时长和硬性页数；一般页数由内容和练习推断 |
| 主视觉 | 已有项目、工程、产品或作业照片；生成场景只能表现可信业务示意，不能冒充客户真实成果 |
| 品牌与基调 | 品牌色、禁用元素；全套选偏浅或偏深，固定背景、正文、强调色及图表色的角色 |
| 讲师与日期 | 讲师默认米尼；日期取当前明确资料，缺失先待填，不能继承旧课件日期 |
| 输出 | 默认所有页整页生图，PPTX 作为翻页容器，16:9；按用户用途变更画幅和格式，重新检查布局与投影可读性 |

简报可以是一段说明和素材清单，不必另建复杂合同。客户事实与创作判断区分记录；重要事实冲突先核实，普通构图选择自行决定。

## 封面：客户业务与课程价值在同一画面

选择一个能说明客户身份的业务主角，例如盾构施工、桥梁建设、生产线、核心产品或真实业务现场。辅助数字元素服务课程主题，不能把多个工程、地标和科技符号堆成拼盘。已有照片适用时优先使用；需要创作时，让场景与标题共享光照、动势或空间关系。

- **左上 Logo**：使用真实原件，保持图形、文字、组合、比例和标准色；留出清晰净空。背景干扰时设置干净承托区，不拉伸、不重画。
- **主标题**：高亮金色中文手写体，具有笔锋、粗细变化、飞白或连贯动势；字形飘逸凌厉，但不能牺牲正确汉字和投影可辨识性。金色承担课程主标题，客户标准色仍用于品牌身份。
- **底部信息**：姓名与日期采用稳定易读字体，用准确小字合成，保留源字段、素材与未加底部信息的原图，方便更新后重新输出。副标题、客户名等准确小字采用同样方式；默认整页图片成品不承诺这些文字可单独编辑。
- **生成边界**：封面背景与手写主标题在同一次整页生成中完成；原始 Logo 最终确定性叠加。封面图像模型仅允许生成逐字锁定的主标题，避免生成伪文字、页码、水印和错误小字。这个唯一标题规则只适用于封面，内页标题与正文需要随整页直接生成。

### 封面提示参数模板

先把方括号替换为真实内容；缺失事实不要补写。主标题艺术字需逐字复核，Logo 和底部文字随后准确合成到最终封面，保留源素材与文案字段。

```text
用途：中文企业培训课件封面，画幅 [16:9 或当前指定比例]。
客户依据：[客户正式名称]；已核验业务锚点：[一个核心工程/产品/作业场景]。
课程价值：[学员本次要实现的具体工作变化]。
场景依据：[真实照片/资料路径，或明确的行业示意]。

构图：以 [业务主角] 为主视觉，[少量辅助元素] 支持课程主题。
左上预留干净的真实 Logo 区，保持足够净空；不要生成 Logo。
底部预留讲师姓名和培训日期的清晰区；不要生成这些小字。
全套基调：[偏浅或偏深]；背景色角色：[说明]；品牌色角色：[说明]。

唯一允许生成的文字：“[逐字锁定的课程主标题]”。
标题为高亮金色中文手写艺术字，笔锋明确、粗细有变化、飘逸凌厉、构图有冲击力。
文字与 [场景光照/空间动势/材质] 呼应，保持每个汉字正确、完整、清楚。
不生成副标题、讲师、日期、网址、页码、水印、标签或任何伪文字。
```

不要为了形式上的“一体化”将字藏进复杂物体或强光中。若艺术字错字，调整断行、字形复杂度或构图后重新生成；不能用后期普通无衬线金色字覆盖来冒充直接生成的手写标题。

## 全套设计系统与字号

默认 16:9。确定背景、主色、强调色、中文正文字体、标题字体、图标线宽、图表样式、边距和章节页结构后，全套持续使用。偏浅或偏深是主基调，局部层次可以变化；不强制章节换色或深浅交替。真实界面截图保留其颜色，通过统一裁切、边距和标注融入整体。

正文优先按 **28 pt 左右或更大**、标题按 **40 pt 左右或更大** 的视觉尺度设计；建议正文 28–32 pt、标题 40–48 pt，封面标题按长度与画幅放大。这是优先目标，不是逐字严格门槛：信息密集页的表格、标签、步骤或必要正文可适度放宽，但必须在最终画幅和实际投影观看下清楚。整页图像没有可核验的原生字体字号，PPTX 的 pt、网页的 px 和图片像素也不能混用，不能只凭提示词写过 28/40 就宣称字号通过。

放不下时优先删重复表述、保留结论和关键词、将细节移入讲师备注，或拆成总览与分解页。密集页需要适度减小时，仍保持标题与正文层级，避免连续整页小字；最终以投影可读性核查结果决定保留、放大或拆页。艺术标题的尺寸、汉字准确性与最终投影清晰度单独检查。

版式由教学目的决定：概念解释、操作截图、比较表和结果证据可以有不同图文比例，不机械套 70/30。保持信息层级与对齐一致，用构图变化形成节奏；不要求相邻页都刻意换布局。

## 所有页面直接生图

封面、章节页、概念页、操作页、结果页与结束页都必须实际调用当前可用的 ImageGen，或当前环境确有可调用能力的 Images 2.5，直接生成整页图文。内页标题、正文、标签和一般图示随页面生成；不能只生成背景后把普通标题与正文全部原生覆盖，再称为整页直接生图。

使用当前工具实际提供的路由与参数。只有工具结果能确认时才报告具体模型版本；工具没有模型选择参数或返回版本时，不得把 ImageGen 调用称为已成功调用某个 2.5 模型。保留每页生成结果与实际调用记录，成功页复用，只重做失败或受影响页。

真实 Logo、二维码、真实 UI 及必须准确的源对象允许保留原件，作为参考输入或在生成页上准确合成。合成不代替普通内页图文的直接生成；逐字核对生成文字、数字、单位和关系，错误页优先重新生成。PPTX 收纳整页图片并提供翻页，不能称为原生可编辑课件；只如实说明确有独立叠加的对象。

### 内页提示参数模板

```text
生成一张完整培训课件页面，画幅 [当前比例]；沿用 [已验证封面/参考页] 的 [浅/深] 基调、配色、字体感觉与行业素材语法。
教学目的：[本页一个主要观点或任务]。
本页标题：“[逐字锁定标题]”。
本页正文/标签：“[精简并逐字锁定的内容]”。
图示逻辑与行业场景：[内容对应关系、输入/输出或关键步骤]。
整体构图：[标题、主体、证据和留白的位置与比例]。
标题优先约 40 pt、正文优先约 28 pt 的视觉尺度；[是否为密集页、允许适度缩小的局部]；保证最终投影可读、层级清楚。
标题、正文与图示在同一整页图像中直接生成，不留空白供后期普通文字覆盖。
[需保留源件的 Logo/二维码/真实 UI] 预留 [位置]，不得重画源件内容；除此以外不新增文字、水印或无关元素。
```

## 教学页型

按本次课程选择必要页型，不必逐章配齐。每页支撑一个主要观点或任务。

| 页型 | 应呈现的内容 | 合适的视觉组织 |
|---|---|---|
| 开场问题 | 客户岗位、真实难题、预期交付物 | 一项任务与当前/目标状态对照 |
| 章节导航 | 当前位置、阶段目标、与上一阶段的关系 | 固定章节母版与行业主视觉 |
| 概念解释 | 一个结论、关系或方法 | 对比、层级、流程、矩阵；术语服务后续操作 |
| 工具选择 | 当前任务、选择依据、适用条件 | 少量可比较维度，避免只有 Logo 列表 |
| 操作示范 | 要完成什么、关键步骤、正确状态 | 真实截图局部放大，统一编号与强调框 |
| 输入与结果 | 输入材料、生成结果、发生了什么变化 | 并排或上下对照，标出需要复核的部分 |
| 学员练习 | 任务、可用输入、提交物、完成判据 | 清晰任务卡；操作细节进入备注或配套材料 |
| 讲评复核 | 典型错误、判断依据、修改方法 | 正反例与验收清单，事实与演示数据分清 |
| 迁移行动 | 回岗可执行的第一项任务及责任 | 小范围行动步骤，避免空泛口号 |

长提示词、完整报告和原始大表不宜承担投影页正文。整张结果图可作证据总览；需要学员读懂或执行的细节必须另做放大、重排或拆页。

## 岗位实操链条与行业迁移

每个案例形成 **业务问题 → 输入材料 → 关键操作 → 交付结果 → 复核标准**。说明结果如何进入实际工作，学员提交什么以及怎样判断正确；能提供真实材料时优先使用，模拟材料清楚标识。

行业迁移同时检查三个方面：图片是否对应当前论点，任务与资料是否属于学员岗位，结果与检查标准是否能在该行业使用。只替换 Logo、地标和背景不算完成迁移。

| 行业例子 | 适合的输入与任务 | 可检查的结果 |
|---|---|---|
| 工程/物资设备 | 会议记录、采购与库存表、设备点检、项目报告 | 责任与期限、数量和单位、异常依据、参数来源 |
| 制造 | 工单、质量记录、设备日志、作业指导书 | 问题定位、记录完整性、步骤顺序、人工复核点 |
| 医疗器械/医疗服务 | 已获授权或脱敏资料、培训手册、服务流程 | 来源与专业复核；AI 输出定位为辅助 |
| 零售/服务 | 客户反馈、销售与库存、活动记录 | 分类是否合理、数字是否一致、行动是否可执行 |

例子用于选题，不固定任何行业模板。保留生活化引入时应简短，并及时回到客户岗位；工具更新、入口、日期、排名和效果数字在复用时重新检查。
